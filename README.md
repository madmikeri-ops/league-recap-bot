# League Recap Bot

Personal fantasy football analytics and automated weekly recap tool for a private Yahoo Fantasy Football league.

## Overview

League Recap Bot is a personal project designed to automatically collect and analyze fantasy football data from a single private Yahoo Fantasy Football league.

The project is intended for personal use and for the members of the private league. It is not a commercial product or a public fantasy football service.

## Intended Use

The application will retrieve available Yahoo Fantasy Sports data for the authenticated user's private league, including:

* League information and settings
* Teams and managers
* Weekly matchups and scores
* Rosters and player scoring
* Standings
* Transactions and roster activity
* Other available league and player information needed for statistical analysis

The collected information will be stored in a private Google Sheet and used to generate automated weekly statistics, awards, trends, and written league recaps.

## Data Processing

The application will:

1. Retrieve available league data from Yahoo.
2. Preserve raw data for historical reference.
3. Organize and normalize the data.
4. Calculate fantasy football statistics and league trends.
5. Generate a weekly recap.
6. Store the results in a private Google Sheet.

## Scope

This project is limited to a single private Yahoo Fantasy Football league.

It is not intended to:

* Provide a public Yahoo data service
* Sell or redistribute Yahoo data
* Operate as a commercial fantasy football platform
* Access leagues that the authenticated user is not authorized to access

## Access

The application requires appropriate Yahoo authorization to access the user's private fantasy league data. Access will be limited to the data necessary for the application's personal analytics and recap functions.
